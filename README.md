# Campus Lost & Found Hub

## Project idea

Campus Lost & Found Hub is a simple campus notice board where students can report belongings they have lost or found. Users can browse reports, search by item name or location, filter reports, mark an item as recovered, and delete a report.

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla JavaScript)

## Files

- `index.html` – page structure and report form
- `style.css` – page design and responsive layout
- `script.js` – sample reports, form validation, search, filters and DOM operations

## Practical concepts demonstrated

| Practical | Concepts |
|---|---|
| 1 | Semantic HTML5 structure; project can be managed using Git and GitHub |
| 2 | CSS selectors, box model, Flexbox, Grid and media queries |
| 3 | Variables, arrays, conditions, loops and functions |
| 4 | DOM selection, creating/appending elements, event listeners and dynamic updates |
| 5 | HTML form attributes and JavaScript client-side validation |

## Important limitation

This is a front-end demonstration. Reports are stored in a JavaScript array while the page is open. Refreshing the page resets the reports to the sample entries. Reports are not shared with other users or devices because this project does not include a backend or database.
