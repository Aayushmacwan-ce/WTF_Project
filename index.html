ABOUT THIS PROJECT

A small step towards a helpful campus

Campus Lost & Found Hub is a front-end student project that provides a simple place to list lost and found belongings. It demonstrates HTML forms, CSS layouts and JavaScript interactivity.

Remember

Do not post sensitive personal information or full details from an ID card. Verify ownership before handing over an item.
